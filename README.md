# Boss Shop

Десктопная программа для Windows 11: товары, склад, продажи, возвраты, расходы и чистая прибыль магазина мужской одежды.

## Возможности

- связанные справочники категорий, подкатегорий, размеров, поставщиков и сотрудников;
- варианты товара по размеру и цвету, поиск и фильтры, предупреждения о низком остатке;
- поступления, продажи, возвраты и списания с автоматическим изменением склада;
- сохранение закупочной и розничной цены на момент продажи;
- расходы, аренда и зарплата с указанием отчетного периода;
- dashboard за день, неделю, месяц, квартал, год или произвольный период;
- аналитика по категориям, товарам, размерам и брендам;
- отчет «Прибыль и убытки» и расчет маржинальности;
- история складских операций;
- экспорт таблиц и отчетов в Excel, CSV и PDF;
- роли «Администратор» и «Продавец». Продавцу недоступны закупочные цены, расходы и прибыль;
- локальная SQLite-база, работа без сервера и интернета.

## Первый вход

- Администратор: `admin` / `admin123`
- Продавец: `seller` / `seller123`

После первого входа создайте собственных пользователей в разделе «Настройки → Пользователи».

## Разработка

```powershell
npm install
npm run dev
```

Проверка и сборка:

```powershell
npm run check
npm test
npm run build
npm run dist
```

Установщик создается в папке `release`.

## Данные и резервная копия

Рабочая база хранится в профиле текущего пользователя Windows, в каталоге приложения `boss-shop`, файл `boss-shop.sqlite`. Для резервной копии закройте программу и скопируйте этот файл в безопасное место. История продаж не удаляется при архивировании товаров и справочников.

Денежные суммы в базе хранятся целыми копейками, поэтому расчеты не накапливают ошибки округления.
